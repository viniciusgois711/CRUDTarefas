# To-Do List App (Angular + PO-UI)

## Descrição
Este é um aplicativo de To-Do List simples, desenvolvido com **Angular** e a biblioteca de componentes **PO-UI**. A aplicação permite aos usuários adicionar, editar e excluir tarefas, além de listar as tarefas.

## Funcionalidades
- Adicionar novas tarefas
- Editar tarefas existentes
- Excluir tarefas
- Listar tarefas

## Tecnologias Utilizadas
- **Angular** (Framework para construção de SPAs)
- **PO-UI** (Biblioteca de componentes para interface de usuário)
- **TypeScript** (Linguagem utilizada no desenvolvimento)
- **HTML/CSS** (Estrutura e estilo da aplicação)

## Pré-requisitos

Antes de rodar o projeto, certifique-se de ter o seguinte instalado:

- **Node.js** (versão 14.x ou superior)
- **Angular CLI** (versão 12.x ou superior)
